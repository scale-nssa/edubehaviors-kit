# EduBehaviors-Kit 0.2.0

New assertion set.

## Changed

- `AssertionAnnotator` and `ClassificationPipeline` now use a new set of 102 assertion classifiers,
  replacing the 49 `sentence_*` assertions from 0.1.x. The new assertions come from a bottom-up and a
  top-down assertion set, and are listed on the assertions page of the documentation.
- The assertion classifiers are trained on a new, larger LLM-annotated subset of the TalkMoves
  dataset, published at `StanfordSCALE/assertions_llm_annotated_talkmoves`.

## Documentation

- The assertions table, usage docs, README, and example notebook use the new assertions.
- The README and usage docs now point at `examples/talkmoves.csv`.
